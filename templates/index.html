Using the visualizer

Each algorithm in the list above has its own page, which animates the sort on a shuffled list of numbers drawn as bars whose height and color show their value. On that page, set the number of bars with the slider, choose a speed with the fps buttons and press Start. Pause stops the animation where it is, Start resumes it, and Reset shuffles a new list. A black bar marks the position the algorithm is working on at each step, and below the animation the page explains the algorithm and shows it in JavaScript, Python and Java.
